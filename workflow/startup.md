请先只读了解选定的项目目录，完成启动交接。此时尚未给出新的具体任务或学习主题。

1. 确认当前路径，读取适用的项目约定，查看目录结构（包括相关隐藏文件）。项目范围保持为选定目录。
2. 根据实际内容选择下一步：
   - **空目录或尚无实质项目内容**：简短说明目录状态，表示可以安排新任务，询问要做什么以及希望交付什么。有初始化文件时如实说明；此阶段保留目录原状。
   - **已有项目内容**：先理解背景再交接。优先读 README、AGENTS.md 指向的说明、项目现有的进展/重启/交接材料及 `.workstyle/tasks/`；沿用项目已有的信息来源和读取方式。按需检查代码入口、配置、数据版本与关键产物；有 Git 时核对与本目录有关的工作区变化和近期提交。先建立整体结构，再围绕当前进展补齐证据，跳过依赖目录、构建产物、海量原始数据和凭据内容。
3. 对已有项目，用中文给出简明交接摘要：项目目标和主要组成、关键文件及运行或数据流程、已完成和正在进行的事项、未完成事项或阻塞、建议接手点。重要判断附文件依据；区分记录里的说法、当前可核对的事实与推断。找不到的背景、过期记录或状态冲突应明确说明。
4. 空目录等待用户安排新活；已有项目根据具体交接结果给出少量下一步选择，例如继续某项未完成工作或安排新任务，等待用户指定。旧任务记录在本阶段仅用于理解背景，即使只有一个未完成任务也先展示交接结果。

启动了解仅做只读检查，不安装依赖、运行项目或修改文件；任务记录、课程和项目改动都等用户给出具体请求后再开始。这一轮的完成条件是有依据的目录判断及交接说明，不是创建新的工作产物。
